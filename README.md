# QuickSlot

A clean rebuild for Graphic Era Hill University, Dehradun. The original implementation remains recoverable from Git history before branch codex/02-clean-foundation.

## Workspace

- apps/api: Python API, scheduling rules, persistence and tests
- apps/web: React and TypeScript interface
- infra: deployment configuration
- data/sources: timetable evidence, not published schedules
- docs/rework: architecture, workflows and audits
- docs/pull-requests: numbered local PR descriptions and merge order

Follow docs/rework/architecture-plan.md for intended behavior. Implementations are prototypes until the documented release gates have passed. No university-wide coverage is claimed.
